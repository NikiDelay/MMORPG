##  Выполненные задачи

### Задача 1. Основные классы 
- Реализован класс игрового поля `GameField` с контролем максимального количества объектов
- Поддерживается добавление и удаление юнитов, нейтральных объектов и баз
- Реализовано **глубокое копирование поля** через `copy.deepcopy` (включая все объекты)
- Создан базовый класс `Unit`, реализующий интерфейс `IUnit`
- Реализовано **7 типов юнитов протоссов** в 3 категориях:
  - **Ближний бой:** Зилот, Тёмный тамплиер
  - **Дальний бой:** Драгун, Сталкер
  - **Тяжёлая техника:** Опустошитель, Бессмертный, Колосс

### Задача 2. Интерфейсы и взаимодействие 
- Реализована **база** (`GameBase`) с созданием юнитов и учётом лимита
- Созданы **3 типа ландшафта**: Равнина (`.`), Лес (`+`), Гора (`M`)
- Ландшафт влияет на юнитов через параметр `move_cost`
- Реализовано **4 типа нейтральных объектов**: Святыня, Ловушка, Сундук, Узел ресурсов
- Взаимодействие юнитов с нейтральными объектами реализовано через **перегрузку оператора `+`** (`unit + neutral_object`)

### Задача 3. Взаимодействие пользователя с игрой 
- Реализован консольный интерфейс через класс `GameEngine`
- Поддерживаются команды: `spawn`, `move`, `status`, `map`, `copy`, `help`, `quit`
- Управление базой (создание юнитов) и юнитами (перемещение по координатам)
- Вывод состояния базы, списка юнитов и карты

### Задача 4. Добавление функционала (Вариант 19) 
- Реализован класс `JsonManager` для работы с JSON-файлами
- Поддерживаемые операции: **чтение**, **запись**, **добавление**, **изменение**, **удаление** ключей
- Класс `GameLogger` использует `JsonManager` для **логирования всех событий игры** в файл `game_session.json`
- Логи содержат временные метки, тип действия и описание
